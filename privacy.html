Hermes Local - Privacy Policy

Last updated: September 20, 2026

Hermes Local is a personal, self-hosted agent environment operated by Eric Olombel.

Data accessed

When enabled by the user, Hermes Local accesses Google account data through Google OAuth only to provide the Google-related functionality requested by the user. The application requests only the permissions selected during authorization.

How data is used

Google data is used solely for the user's own workflows. It is not sold, rented, or used for advertising, and is not shared with third parties except where a user explicitly directs Hermes to use an enabled integration.

Storage and security

OAuth credentials and tokens are stored in the user's local Hermes environment. The user controls the local machine, the Hermes configuration, and the connected services.

Retention and deletion

The user may remove the connection from Hermes and revoke access at any time from their Google Account security settings. Local credentials can also be removed from the Hermes environment.

Contact

For questions about this application, contact eolombel@gmail.com.
