# rico34fr.github.io

Page vitrine consulting d'Eric Olombel (transformation finance, IA appliquée à la finance, systèmes et ERP).

- `index.html` : page autonome bilingue FR/EN (`?lang=fr|en`), sans dépendance hormis Google Fonts
- `assets/video/` : vidéo de présentation compressée, affiche, sous-titres FR (`subs-fr.vtt`, superposés aux sous-titres anglais incrustés)
- `assets/img/` : écrans d'outils extraits de la vidéo
- `assets/og-image.png` : image de partage 1200x630
- `privacy.html`, `terms.html` : pages de l'app Hermes Local, conservées telles quelles
- Le CV en ligne vit dans le repo `cv` (https://rico34fr.github.io/cv/)
